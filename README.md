# ELI-5-Client Advanced

**ELI-5-Client Advanced** is a customized, high-performance client build for [Luanti](https://www.luanti.org/) (formerly Minetest), optimized for modern gameplay and custom feature integration.

## About The Project

This repository serves as the official source for the ELI-5-Client build of Luanti. It includes custom interface tweaks, build updates, and performance modifications tailored for cross-platform play.

### Key Features
* Fully compliant with Luanti 5.18.0 engine updates.
* Enhanced mobile and ARM64 compatibility.
* Custom user interface and gameplay optimizations.
